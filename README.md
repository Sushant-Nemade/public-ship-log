# Public Ship Log

Next.js demo with a local timeline and time-zone-aware daily streak counter. The sample timeline can be edited in the current browser; entries are kept in local storage.

Run `pnpm install`, `pnpm --filter public-ship-log dev`, then open `http://127.0.0.1:3009`. Run `pnpm --filter public-ship-log test` for the streak test.

This preview does not have a shared server database, authenticated administrator, image storage, or Twitter/X and LinkedIn posting. Those features require accounts and privacy choices before a production deployment. The demo never posts to social media.
